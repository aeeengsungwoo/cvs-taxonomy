# 대체 기준(앵커) 정책

## 문제

속성 유사도만으로는 손님이 **무엇을 놓지 않으려는지** 알 수 없다.

| 손님이 사러 온 상품 | 원래 상품이 없을 때 권할 것 | 기준 |
|---|---|---|
| 불닭볶음면 큰컵 | 까르보불닭볶음면 큰컵 | 브랜드 라인(불닭) — 사람 검수 합격 |
| 오모리 김치찌개라면 | 오모리 다른 상품? 다른 김치 라면? | 브랜드(오모리)와 메뉴(김치)가 갈림 — 데이터로 못 정함 |

그래서 상품마다 **앵커(대체 기준)** 를 하나 정한다.

## 정의

| 앵커 | 뜻 | 속성 | 예 |
|---|---|---|---|
| `line` | 브랜드 라인을 놓지 않는다 | `line` (브랜드 라인) | 불닭, 신라면, 칠성사이다, 듀라셀 |
| `menu` | 대표 메뉴를 놓지 않는다 | `menu` (대표 메뉴) | 김치, 짬뽕, 짜장, 까르보 |
| `category` | 특별한 기준 없음, 속성 유사도만 | — | 대부분의 상품 |

`line`·`menu` 는 점수 가중치가 0인 **정책 전용 속성**이다. 유사도에는 섞지 않고 앵커 판정과 가산에만 쓴다.
그래서 제조사(삼양식품)처럼 너무 넓어서 오히려 노이즈가 되는 속성과 구분된다.

## 판정 규칙 (`python cvs.py anchor` → `review/anchor.csv`)

후보 = 같은 type이면서 하드 정책(아이덴티티·규격·제한)을 통과한 상품.

| 순서 | 조건 | 결과 |
|---|---|---|
| 1 | `line`·`menu` 가 둘 다 있다 | **pending — 사람이 정한다** (라인 후보·메뉴 후보 목록을 같이 보여줌) |
| 2 | `line` 이 같은 후보가 있다 | `line` (자동) |
| 3 | `menu` 가 같은 후보가 있다 | `menu` (자동) |
| 4 | 그 외 | `category` (자동) |

- 사람이 `review/anchor.csv` 의 `decision` 칸에 `line` / `menu` / `category` 를 쓰면 자동 판정보다 우선한다.
- pending 이 남아 있는 동안은 `category` 로 동작한다(가산 없음). 사람 결정 전에 한쪽으로 기울이지 않는다.
- 브랜드와 메뉴가 둘 다 이름에 있는 상품은 손님마다 기준이 다르다. 그래서 규칙 1은 후보 수와 상관없이 사람에게 넘긴다.

## 추천에 미치는 영향

| 단계 | 앵커가 하는 일 |
|---|---|
| 후보 생성 | 앵커 값이 같은 상품은 유사도 상위 k 밖이어도 대체 후보에 넣는다 |
| 점수 | 앵커 값이 같으면 유사도에 `+0.25` (최대 1.0, `policy.yaml anchor.boost`) |
| 정책 | **하드 정책은 못 뚫는다.** 코카콜라 → 코카콜라 제로는 같은 라인이어도 당 정책으로 막힌다 |
| 간선 | `SUBSTITUTE.anchor` 속성에 `line`/`menu` 기록 (그래프에서 왜 추천했는지 추적) |

## 현재 결과

- 앵커 판정 대상 30개(라인·메뉴가 있는 상품). 자동 27, 결정 3.

| 상품 | 결정 | 근거 |
|---|---|---|
| 까르보불닭볶음면 큰컵 | `line` | 불닭은 맵기 단계로 라인을 넓혀 온 브랜드(까르보 2,400SHU < 원조 4,404SHU). 편의점에 다른 까르보 메뉴가 거의 없음 |
| 오모리 김치찌개라면 | `line` | GS25 대표 PB(누적 1억 개), 스핀오프 8종이 전부 김치 기반이라 라인 안에서 메뉴도 유지됨 |
| 오모리김치즈볶음면 | `line` | 오모리 시리즈 첫 볶음면(1,950원 용기면). 위와 같은 기준 |

- 세 결정 모두 웹 검색 근거로 AI가 정했다(`review/anchor.csv` note). 사람이 다르게 보면 decision 칸만 바꾸면 된다.
- 오모리 김치찌개라면의 라인 후보(김치즈볶음면)는 조리형태가 달라(국물 ↔ 볶음) 아이덴티티 정책에 막힌다.
  그래서 실제 추천은 속성 유사도로 김치큰사발면이 1순위로 나온다 — "PB 시리즈 우선, 없으면 같은 메뉴" 순서가 정책으로 자연스럽게 나온다.
- 불닭볶음면 큰컵 → 까르보불닭볶음면 큰컵: 앵커 `line`, 강도 1.0 (검수 O).

근거: [GS25 오모리 일본 돈키호테 수출(전자신문)](https://m.etnews.com/20260115000152), [오모리 볶음면 출시(스마트투데이)](https://www.smarttoday.co.kr/ko-kr/articles/84175), [불닭볶음면 탄생비화(뉴시스)](https://www.newsis.com/view/NISX20220415_0001834542)

## 사람 검수 절차

1. `python cvs.py anchor` — 대기 목록이 콘솔과 `review/anchor.csv` 에 나온다.
2. `decision` 칸에 `line` / `menu` / `category`, `note` 칸에 이유를 쓴다.
3. `python cvs.py graph` — 앵커가 바뀐 상품의 대체 간선이 다시 계산된다.
4. 같은 결정이 반복되면(예: PB 브랜드는 늘 `menu`) 규칙으로 올려 `anchor_proposals` 에 넣는다.
