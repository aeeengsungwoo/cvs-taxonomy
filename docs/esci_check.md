# Amazon ESCI로 대체 정책 검증

데이터: [amazon-science/esci-data](https://github.com/amazon-science/esci-data) (Shopping Queries Dataset, Apache-2.0, Reddy et al. 2022).
검색어 13만 개 × 상품 260만 쌍에 사람이 붙인 라벨. US·JP 중 편의점 관련(탄산·커피·라면·과자·건전지·구강·면도) 25,079쌍만 썼다.
원본(1.1GB)은 커밋하지 않고, 결과만 `out/esci_policy_check.csv`, 샘플은 `out/esci_samples.csv` 에 있다.

| 라벨 | 정의 (논문) |
|---|---|
| E | 질의의 모든 조건을 만족 |
| S | 일부 조건은 못 맞추지만 기능상 대체 가능 |
| C | 질의를 만족하진 않지만 같이 쓰는 상품 |
| I | 무관하거나 **핵심 조건을 어김** (예: 글루텐프리 빵 질의에 일반 밀가루 빵) |

I의 정의는 우리의 "제로 → 일반 금지"와 같은 생각이다.

## 판단

**품절 대체 정책의 정답으로는 쓸 수 없다.**

1. ESCI가 재는 것은 "검색 결과에 보여줄 만한가"이지 "품절일 때 대신 사겠는가"가 아니다. 그래서 핵심 조건을 어긴 상품에도 S, 심지어 E가 붙는다.
   예: "decaf k-cup coffee pods" → 일반 커피 E, "aa batteries" → AAA E, "big red zero soda" → 일반 Big Red E.
2. 방향 차이(제로 → 일반 vs 일반 → 제로)가 라벨에서 거의 드러나지 않는다. 쌍 수도 14~63개로 적다.
3. 미국·일본 아마존 상품이라 한국 편의점 상품·브랜드 라인과 겹치는 게 적다. 질의 → 상품 구조라 상품 → 상품 대체와도 다르다.

**쓸 수 있는 것**

- 라벨 체계(E/S/C/I)는 설문 답안 형식으로 그대로 쓴다. "그대로 산다 / 대신 산다 / 같이 산다 / 안 산다".
- 브랜드 충성도가 카테고리마다 다르다는 신호는 일관된다. 탄산(펩시 질의 → 다른 브랜드 87% I)은 브랜드를 지키고, 건전지·라면(다른 브랜드 86~93% S)은 브랜드를 넘어 대체된다.
  → 앵커 정책의 사전값으로 쓸 수 있다: 탄산은 line, 건전지·라면은 category 쪽.
- 규격 정책(AA ↔ AAA)은 방향 상관없이 I가 기준선(0%)보다 확실히 높다(19~50%). 금지 유지가 맞다.
